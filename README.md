# Word Counter

A simple and responsive web application that counts words and characters in real time. Built with HTML, CSS, and Vanilla JavaScript.

## ✨ Features

- **Real-Time Word Counting:** Automatically counts words as you type.
- **Character Counting:** Displays the total number of characters.
- **Clear Text:** Quickly clears the input area and resets the counters.
- **Simple Navigation:** Navigate between Home and About sections.
- **Direct URL Navigation:** Supports opening specific sections using URL hashes.
- **Responsive Design:** Designed to work across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structures the web application.
- **CSS3** – Handles styling and responsive layout.
- **Vanilla JavaScript** – Implements the application's functionality and interactivity.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/jaafarjab77-tech/Word-Counter.git
```

### 2. Navigate to the project directory

```bash
cd Word-Counter
```

### 3. Run the application

Open `index.html` in your web browser.

No additional dependencies or installation steps are required.
